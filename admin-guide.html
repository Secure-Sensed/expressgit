🚀 Getting Started

Step 1: Access the Admin Console

  • Open your browser and navigate to /admin-login
  • Enter your admin credentials:
    • Email: Your registered admin email
    • Password: Your admin account password
  • Click Sign in
  • You'll be redirected to the main Admin Console dashboard

Step 2: Review the Onboarding Guide

On your first sign-in, you'll see the Admin First Sign-In Guide card. Key takeaways:

  • Search before creating new shipments
  • Always enter receiver email for notifications
  • Update location and status when shipments change
  • Reply to customer support messages
  • Monitor email notification status

Click Mark as done to dismiss this guide.

📊 Dashboard & Stats

The dashboard displays four key metrics at the top of your screen:

Metric Description Use Case

In transit Shipments currently moving Monitor active shipments
Delivered Completed shipments Track success rate

Refresh Button

  • Click Refresh data to reload all statistics and shipment lists
  • Shows a spinner while loading

Sign Out

  • Click Sign out to end your admin session
  • You'll be logged out and returned to the login page

📋 Shipment Inventory

Finding Shipments

The Shipment Inventory panel on the left lists all available shipments.

Search

Enter any of the following in the search box:

  • Tracking number (e.g., 771975185243)
  • Reference number (e.g., REF-INTL-1001)
  • TCN code
  • Origin city (e.g., Memphis)
  • Destination city (e.g., Los Angeles)
  • Customer email or name

Results update in real-time as you type.

Filter by Status

Use the Filter status dropdown:

  • All statuses - Show all shipments
  • Pending - Awaiting processing
  • In Transit - Currently moving
  • Out for Delivery - On final vehicle
  • Delivered - Completed
  • Exception - Issues or delays
💡 Tip: Combine search and filter for precise results (e.g., search "Atlanta" + filter "Delivered")

Selecting a Shipment

Click on any shipment to:

  • Load it into the detail editor on the right
  • View and edit all its information
  • Access its support thread messages
  • Update its location

➕ Creating Shipments

Method 1: Quick Create (Recommended for Speed)

Steps

  1. Select Status Preset
    • Pending: Memphis → Atlanta (3 days)
    • In Transit: Indianapolis → Newark (1 day)
    • Out for Delivery: Dallas → Austin (same day)
    • Delivered: Indianapolis → Atlanta (with receipt)
    • Exception: Phoenix → Newark (delayed, 2 days)
  2. Enter Customer Email (Recommended)
    • E.g., customer@example.com
    • Without this, no notification email will be sent
    • Customer name is auto-populated from the email
  3. Generate Parcel
    • Click Generate parcel
    • Tracking number is automatically created
    • Success message appears with new tracking number
Method 2: Full Shipment Editor (Complete Control)

Form Fields

Field Description Required
Tracking Number Unique identifier (auto-generated if blank) No
Reference Number Customer or internal reference No
Status Current shipment status Yes
Origin Pickup location Yes
Destination Delivery location Yes
Last Location Current location of package Yes
Customer Email For notifications and support No
Estimated Delivery Expected delivery date & time No

Event Details (Optional)

Add an initial shipment event:

  • Event Title: Description (e.g., "Shipment picked up")
  • Event Location: Location of event
  • Event Details: Additional notes

Save

  • Click Save shipment
  • Tracking number auto-generated if not entered
  • Email notification sent if customer email provided

✏️ Editing Shipments

Opening an Existing Shipment

  • Use Search in Shipment Inventory to find the shipment
  • Click on it in the list
  • The detail editor populates with its current data

Common Edit Scenarios

Update Status and Location

  • Find shipment by tracking number
  • Change Status dropdown (e.g., "In Transit" → "Out for Delivery")
  • Update Last Location to new city/address
  • Add an event describing the change
  • Click Save shipment
  • Notification email sent to customer

Mark as Delivered

  • Select the shipment
  • Change Status to "Delivered"
  • Fill in Proof of Delivery:
    • Set delivery timestamp
    • Enter recipient name (e.g., "Front Desk")
  • Click Save shipment
  • Delivery notification email sent

Deleting a Shipment

  • Select the shipment from inventory
  • Scroll to bottom of detail editor
  • Click Delete shipment button
  • Confirm in the popup dialog
  • Shipment is removed
⚠️ Warning: Deletion cannot be undone. Confirm you're deleting the correct shipment.

📍 Live Location Updates

The Live Location Update panel provides a quick way to update a shipment's current location.

Steps

  1. Tracking Number
    • Auto-populated from selected shipment
    • OR type a different tracking number
  2. Current Location
    • Enter new location (e.g., "Chicago, IL")
  3. Update Location
    • Click Update location
    • System saves and sends notification email

When to Use

  • Quick status updates for active shipments
  • Notification of milestone locations
  • Minimal data entry required

💬 Support Inbox

Understanding Support Threads

Support threads are conversations between customers and admin tied to specific tracking numbers.

Viewing Support Threads

The Support Inbox panel shows all recent threads:

  • Each thread shows:
    • Tracking number
    • Last message preview
    • Timestamp (e.g., "2 hours ago")
  • Click any thread to focus that shipment
  • Load conversation history

Replying to Customers

  1. Select a thread from the list
  2. Read the conversation to understand context
  3. Type your admin response in the reply box
  4. Click Send admin reply
  5. Message is saved; conversation updates immediately

What to Include in Replies

  • Shipment status updates
  • ETA information
  • Notes on any issues or delays
  • Escalations if needed

👥 User Management

The Registered Users panel shows all local authentication users.

Viewing Users

Each user card displays:

  • User name (if registered)
  • Email (login identifier)

Removing a User

  1. Find the user in the list
  2. Click Remove button
  3. Confirm the deletion
  4. User account is deleted
  5. That email can be re-registered later
⚠️ Warning: Removed users lose access and cannot log back in.

📧 Email Notifications

How Notifications Work

When you create or update a shipment with a customer email:

  • System attempts to send an email notification
  • Status appears in a toast (popup message)
  • Success or error message displayed

Notification Status Messages

Message Meaning Action
"Receiver email notification sent." Email successfully delivered None; customer notified
"Email notification failed: [error]" SMTP or network error Check email configuration
"No receiver email found for this shipment." Customer email field empty Add email and re-create shipment
"Email not configured..." Environment variables missing Set RESEND_API_KEY and MAIL_FROM

Configuration for Email

To enable email notifications, set environment variables:

  • RESEND_API_KEY - API key from Resend
  • MAIL_FROM - Sender email (e.g., noreply@expressgit.com)

After setting, restart the application for changes to take effect.

🔧 Troubleshooting

Issue: Shipment Not Appearing in Search

Solution 1: Refresh data

  • Click Refresh data button
  • Wait for load to complete

Solution 2: Check filter

  • Try "All statuses" if unsure

Solution 3: Verify tracking number

  • Try partial search (e.g., "771975" instead of full number)

Issue: Email Notifications Not Sending

No customer email entered

  • Ensure Customer Email field is filled

Email service not configured

  • Check that RESEND_API_KEY and MAIL_FROM are set
  • Restart application after setting variables

Invalid email format

  • Confirm email is valid (check for typos)

Issue: Admin Console Blank or Not Loading

Solution 1: Clear browser cache

  • Press Ctrl+Shift+Delete (Cmd+Shift+Delete on Mac)
  • Clear cookies and cache
  • Refresh page

Solution 2: Check admin session

  • If not logged in, log back in

Issue: Support Messages Not Loading

Solution 1: Select a shipment

  • Support messages only show for selected shipment
  • Click a shipment from inventory

Solution 2: Refresh

  • Click Refresh data
